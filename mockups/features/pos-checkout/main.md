POS Checkout (Shopping Cart)

The primary sales interface. Displays selected products, cart summary, and order submission controls.

**Features:**
- Selected products list with quantity, price, and subtotal
- Cart summary showing total, paid amount, discount, and change
- Order lifecycle: add products, recalculate total, submit
- Print-on-submit modes: print-before-save, print-twice
- Keyboard-friendly product code quick-add
- Thermal receipt invoice generation (80mm format)
