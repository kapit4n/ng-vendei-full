Product Catalog Grid

Card-based product grid for selecting items during checkout. Integrated into the POS screen.

**Features:**
- Responsive card grid with product images, prices, and name
- Real-time search by name or product code
- Category filter chips for quick browsing
- Quick-add by typing product code and pressing Enter
- Image fallback chain (presentation → product → placeholder)
- Atomic data loading with forkJoin
